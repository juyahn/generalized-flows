## 전 구간 턴 흐름도

고치려고 읽어야 했던 범위를 전부 그립니다. 턴 하나가 한 줄이고, 각 줄에 **무엇이 실려 가는지**(툴 호출, 고정 응답 템플릿, 상태 플래그)를 같이 적습니다.

```
턴 A  <봇이 무엇을 하는가>        앵커 <NAME> (<playbook 파일> L<n>)
        실려 가는 것: <툴 호출> / <고정 응답 템플릿> / <상태 필드>
턴 B  <유저 입력 형태>
턴 C  ...
```

파일이 여럿이면 고객사·변종별로 줄 번호를 따로 답니다. 같은 이름의 사본이라도 줄 번호가 다릅니다.

## 분기 조건

경로를 바꾸는 것이 무엇인지 적습니다. 상태값, 플래그, 툴 결과 필드, 시각 조건 같은 것들입니다. **유도 과정을 적습니다.** 값만 적으면 다음 사람이 다시 계산합니다.

```
<플래그/값>  =  <어떻게 유도되는가>
  <임계값> 이상 → <어느 경로>
  그 미만      → <어느 경로>
```

도달 불가능한 경로가 있으면 여기 적습니다. 어떤 픽스처로도 들어가지 않는 분기는 검증된 적이 없는 분기입니다.
